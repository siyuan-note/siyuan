## Upgrade notice

Saving new primary-key rich text upgrades the database to format 16, which older clients without format 16 support cannot open. Automatic downgrading is unsupported; rollback requires a complete pre-upgrade snapshot. To retain the ability to roll back, back up your workspace beforehand. Update other devices that sync or access the same data to this version too. Format 15 primary-key rich text remains readable; merely opening a database does not upgrade its format. [Compatibility notes](https://github.com/siyuan-note/siyuan/issues/21136)

## Overview

This release adds rich text and block editing in database primary keys, a built-in date picker, unified color editing, and plugin snapshot browsing and restoration.

Mind maps support per-node connector styles and shapes, freeform node relationships, and configurable relationship paths and line patterns. The standalone Markdown editor adds find and replace, while macOS gains offline Markdown Quick Look previews.

Other improvements include database entry icon controls, document reading position preferences, defaults for expanding or collapsing grouped search results, unused asset cleanup ignore rules, mobile bottom sheet dragging, and KDE system proxy detection on Linux. This release also fixes automatic block collection continuing after a database block is deleted and embedded local HTML attachments opening in an external browser on iOS.
