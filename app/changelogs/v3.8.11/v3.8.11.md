## Upgrade notice

Saving an inline image in a database text field for the first time upgrades that database to format 17. Simply opening a database does not upgrade it. Update all devices that access the same data, as older clients without format 17 support cannot open it. To roll back, restore a complete pre-upgrade snapshot. [Compatibility notes](https://github.com/siyuan-note/siyuan/issues/21527)

## Overview

This release adds rich text and block editing in database primary keys, a built-in date picker, unified color editing, and plugin snapshot browsing and restoration.

Mind maps support custom node and connector styles and freeform connections between nodes. The standalone Markdown editor adds find and replace, while macOS gains offline Markdown Quick Look previews.

Watch the release overview: [YouTube](https://youtu.be/PLbCKqtZw_M)
