## 升级须知

### 数据库格式

- **主键富文本（格式 15 和 16）**。早期预览版保存的格式 15 内联富文本仍可读取。保存新版主键块富文本会将数据库升级到至少格式 16，主键中含图片时同样适用。[主键兼容性说明](https://github.com/siyuan-note/siyuan/issues/21136)
- **普通文本字段内联图片（格式 17）**。在普通文本字段首次保存内联图片时，数据库升级到格式 17。[文本字段兼容性说明](https://github.com/siyuan-note/siyuan/issues/21527)

仅打开数据库不会触发上述升级。3.8.10 最高支持数据库格式 14。客户端只能打开自身支持的数据库格式。使用新格式前，请升级所有同步或访问同一份数据的设备，并备份工作空间。如需回退，请恢复升级前的完整快照。

### 其他兼容性变化

- **AI 长期记忆**。恢复工作空间快照时，记忆记录和撤回状态会一起回滚。恢复到忘记某条记忆之前的快照后，该记忆通过常规有效性检查即可重新使用。[长期记忆说明](https://github.com/siyuan-note/siyuan/blob/64fe75eb55fc783a345ea00fb4db8b60268dd65c/docs/LONG-TERM-MEMORY.zh-CN.md)
- **内核 API**。采用 API 契约的 JSON 请求体上限为 32 MiB，`loginAuth` 的上限为 64 KiB。超限时返回错误码 `-1`。[API 契约说明](https://github.com/siyuan-note/siyuan/blob/64fe75eb55fc783a345ea00fb4db8b60268dd65c/docs/API-CONTRACTS.md)

## 概述

本版本新增数据库主键富文本和多块编辑、内置日期选择器、统一颜色编辑，以及插件快照浏览与恢复。

思维导图支持自定义节点与连线样式、自由连接节点。独立 Markdown 编辑器新增查找替换，macOS 新增离线 Markdown 快速查看预览。
