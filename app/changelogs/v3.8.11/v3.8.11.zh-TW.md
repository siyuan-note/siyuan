## 升級須知

### 資料庫格式

- **主鍵富文字（格式 15 和 16）**。早期預覽版儲存的格式 15 行內富文字仍可讀取。儲存新版主鍵區塊富文字會將資料庫升級至至少格式 16，主鍵含圖片時也適用。[主鍵相容性說明](https://github.com/siyuan-note/siyuan/issues/21136)
- **一般文字欄位行內圖片（格式 17）**。在一般文字欄位首次儲存行內圖片時，資料庫會升級至格式 17。[文字欄位相容性說明](https://github.com/siyuan-note/siyuan/issues/21527)

僅開啟資料庫不會觸發上述升級。3.8.10 最高支援資料庫格式 14。用戶端只能開啟自身支援的資料庫格式。使用新格式前，請升級所有同步或存取同一份資料的裝置，並備份工作空間。如需回退，請還原升級前的完整快照。

### 其他相容性變更

- **AI 長期記憶**。還原工作空間快照時，記憶記錄和撤回狀態會一起回復。還原至忘記某筆記憶前的快照後，該記憶通過一般有效性檢查即可重新使用。[長期記憶說明（簡體中文）](https://github.com/siyuan-note/siyuan/blob/64fe75eb55fc783a345ea00fb4db8b60268dd65c/docs/LONG-TERM-MEMORY.zh-CN.md)
- **核心 API**。採用 API 契約的 JSON 請求本文上限為 32 MiB，`loginAuth` 的上限為 64 KiB。超出上限會傳回錯誤碼 `-1`。[API 契約說明](https://github.com/siyuan-note/siyuan/blob/64fe75eb55fc783a345ea00fb4db8b60268dd65c/docs/API-CONTRACTS.md)

## 概述

本版本新增資料庫主鍵富文字和多區塊編輯、內建日期選擇器、統一色彩編輯，以及外掛快照瀏覽與還原。

心智圖支援自訂節點與連線樣式、自由連接節點。獨立 Markdown 編輯器新增尋找取代，macOS 新增離線 Markdown 快速查看預覽。

本版本功能示範：[YouTube](https://youtu.be/PLbCKqtZw_M)
