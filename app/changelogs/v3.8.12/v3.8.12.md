## Upgrade notice

Plugins that rely on the desktop main menu’s previous identifier, `barWorkspace`, should use `barMainMenu` for the button ID and menu events. [Details](https://github.com/siyuan-note/siyuan/issues/21544)

## Overview

This release adds manual ordering for sibling tags and sorting by most recent addition in the tag panel. Mobile image preview gestures and controls are improved, and asset files can now be shared from mobile.

The desktop Markdown editor supports relative document links, and database cell editors are better aligned. This release also adds a Vietnamese interface and a built-in Russian user guide, and introduces the official SiYuan connector for WorkBuddy.
