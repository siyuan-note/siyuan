## 概述

本版本進一步完善文件與資料庫操作，最佳化行動端和跨平台體驗，並增強 AI、命令面板、集市及外掛相關功能。

### 編輯、文件與資料庫

拖曳時的捲動、鍵盤選取區塊、分頁容器、文件與筆記本排序、從範本建立子文件樹等功能得到改進，資料庫也支援上下文篩選和範本欄位值處理，讓編輯和整理更加高效。

### 行動端與跨平台體驗

行動端的 PDF 註釋、導覽、側欄、區塊選取、鍵盤與文字選取、圖片檢視、安全區域適配和工作區互動得到最佳化。桌面端新增遠端核心連線，資料同步支援按需下載資源；同時停止支援 macOS 12，並升級至 Electron 44.2.0。

### AI、整合與可擴充性

智能體會話和模型配置得到改進，支援非 OpenAI 提供者使用 Responses API 和載入 Skill 資源，並完善命令面板、MCP、集市及外掛 API，為 AI 和外掛擴充提供更好的基礎。
