## Overview

This release expands mind maps and database calendars, adds more ways to customize editing workflows, improves mobile interactions and window management, and introduces workspace storage statistics. It also brings performance improvements and new capabilities for AI, MCP, and plugins.

### Editing, mind maps, and databases

Mind maps now have dedicated block types, bracket summaries, and improved node editing and expansion controls. Database calendars support ISO week numbers, week navigation, and scheduling undated items, while database views gain conditional colors. The command panel can insert blocks, assets, and references, and context menu shortcuts can be customized.

### Mobile, window management, and performance

Mobile editing gains optional searchable slash commands, easier Command Palette access, and pinch-to-zoom for mind maps. New window layouts can be saved and restored, and workspace storage statistics help you see how space is used. Startup, synchronization, long document editing, index recovery, Markdown parsing, and large table rendering are improved.

### AI and extensibility

The built-in MCP server now supports OAuth 2.1, and workspace AGENTS.md files can provide custom instructions for the AI agent. Agent and MCP tools can manage Bazaar packages, while plugins gain directory declarations for publish resources and an asset picker with flexible matching.
