## Overview

This release expands database automations, introduces a compact desktop interface, and improves mobile editing, mind maps, AI integrations, and Linux compatibility.

### Databases and editing

Database automations can collect blocks and assign field values using templates. Locked views support temporary sorting, and database attribute panels adopt a single-column layout. Block reference input, outline navigation, callout conversion, and PDF page breaks are also improved.

### Desktop, mobile, and mind maps

The desktop interface gains a compact mode, menus support scrolling with mouse movement, and mind maps offer multiple connector styles and improved layout density. Mobile database panels, table features, and long-press block dragging are improved. iOS Live Photos can be imported, with metadata display and playback available across platforms.

### AI and platform compatibility

AI integrations add the Gemini Interactions API and DeepSeek Search and Fetch APIs, with configurable embedding concurrency and batch size. Linux improvements cover AppImage startup without libfuse2, built-in OCR compatibility with glibc 2.28, and GNOME system proxy detection. This release also upgrades Electron and Mermaid.
