## Upgrade notice

This release automatically migrates notebooks to the new document title mode and supports `/` in document titles.

Before opening a workspace with this version, quit all older clients and upgrade every device that accesses or syncs the same data, including offline devices before they reconnect. Check plugin compatibility before upgrading.

After migration, do not use older versions to open, edit, restore, or sync the same data: changes may be overwritten or lost and propagated through sync. Older clients rejecting some documents does not protect the entire notebook. See [the compatibility details](https://github.com/siyuan-note/siyuan/issues/19938).

## Overview

This release adds support for `/` in document titles and improves mind maps, database automations, mobile editing, and file change detection.

### Mind maps and editing

Mind maps gain themes, global styling, node selection and clipboard operations, improved summaries, and list-style editing interactions.

Tables support adjustable row heights, with improvements to cell activation, text formatting performance, and Markdown list copying and export.

### Databases and navigation

Database automations support collecting block references, attribute name substring and regex matching, and subdocument depth limits.

Backlinks can be filtered by database fields, new database items have configurable opening behavior, and mobile documents can display backlinks at the bottom.

### Platforms and reliability

This release improves iOS text selection and editing, mobile search navigation, sync progress and cancellation, and file change detection for snapshots, sync, and restoration.

It also adds Windows title bar overlay, macOS system proxy detection, TIFF previews, and custom lock screen wallpapers, and updates runtimes and CA certificates.
