# TypeSafe icon

- File: `typesafe.svg` (transparent SVG)
- Source: the [TypeSafe website](https://typesafe.ai/), inline symbol `svg-684955628_986` used by its Home logo link
- Original geometry: one path in a `0 0 16.487 24` viewBox; its path data is preserved verbatim
- Local adaptations: standalone SVG namespace, black monochrome fill, title, and square `-7.7565 -4 32 32` viewBox with transparent padding to retain the card icon proportions
- Retrieved: 2026-10-07

This is the TypeSafe brand mark used to identify the configured provider. No background shape or embedded bitmap is included. It is bundled locally; the application does not load it from the source URL at runtime. The decision cards invert the monochrome mark in dark themes without changing its transparency.
