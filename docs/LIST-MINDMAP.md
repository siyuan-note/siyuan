# 列表脑图

列表脑图是列表块的另一种视图，入口位于列表块菜单 - 切换为脑图视图。列表项菜单不提供这个入口。斜杠菜单和移动端新建脑图直接生成列表脑图，保留原有菜单配置标识。

打开可编辑文档时，编辑器在首次内容渲染前请求内核迁移旧 `mindmap` 代码块。内核在事务串行区读取整份文档，包括折叠和分页未加载的内容；先保存可恢复的文档历史，再通过一次文档事务转换，保留原块 ID、属性、列表层级、正文和任务状态，并为新增子块生成新 ID。转换支持统一撤销和重做；同一编辑器的当前文档只尝试一次，撤销后再次打开文档才会重新迁移。已转换的块不会重复转换，后续同步或导入的旧内容在下次打开时处理。

原文必须完整解析为一个列表块。空内容、列表外正文、多段独立列表或已有脑图配置的异常输入保持原样并显示源码。旧 ECharts 脑图实现已移除；只读、发布、历史和导出页面将旧原文临时解析为列表脑图，派生 DOM 不参与复制和保存。公开的 `Protyle.mindmapRender` 调用入口保持兼容。加密笔记本经请求租约解锁读取，历史保留原始密文，历史写入失败时不执行迁移。

## 交互

- 按住节点拖动，调整同级顺序或父子层级；目标节点上部、中心、下部分别表示放在前面、作为子节点、放在后面，松手后自动布局
- 双击节点正文才创建轻量 Protyle，直接在原节点内编辑；文字选择和输入由编辑器接管
- 节点选中且未编辑时，Tab 创建子节点，Enter 创建同级节点，并进入新节点编辑；虚拟根节点不创建同级节点，编辑状态保留 Protyle 的按键行为
- 编辑节点时随内容增长或缩短实时调整宽度，保留 300px 的最大宽度；仅进入编辑时保持原有尺寸
- 双击虚拟根节点的标题可原地修改，Enter 或移开焦点保存，Esc 取消；留空恢复“当前列表”，标题随列表属性保存并支持撤销
- 编辑能力复用数据库文本字段的轻量 Protyle，同时保留既有图片；不支持编辑的复杂正文保留原数据，可切回列表编辑
- 点击编辑器外部或按 Esc 结束编辑，保存前等待 Protyle 完成待处理输入；候选菜单和格式菜单优先处理 Esc
- 鼠标移入节点时，右侧显示添加子节点的加号；点击后自动展开父节点，并直接进入新节点编辑
- 节点文字位于分支线条上方，线条延伸到节点末端；展开状态下悬停节点显示折叠按钮，折叠后常驻显示隐藏节点数量；空节点以浅色显示“输入文字”，提示不写入正文
- 使用节点旁的按钮添加子节点或折叠，选中节点后按 Delete 或 Backspace 删除（兼容 macOS 的 Delete 键）；最后一个根节点保留，避免产生不能保存的空列表；撤销和重做保留编辑器快捷键，工具栏不再显示对应按钮
- 点击画布空白处或脑图外部取消选中，收起节点样式及关系线设置；点击节点继续选择关系线终点，点击其他区域取消连线
- 连接按钮使用带箭头的弯曲连线图标，位于缩小按钮前；先选择起点，再选择终点，可编辑文字、颜色或删除关系线；路径通过正交可视网格上的 A* 搜索避开节点和折叠、添加按钮区域，减少转弯并绘制圆角，布局变化时重新计算，平移和缩放时复用路径
- 关系线支持直接拖动，选中后在线段上显示手柄；水平线段上下拖动，垂直线段左右拖动，首尾线段保留连接节点的引出段；拖动时固定节点布局和画布，实时预览避障路径，松手保存一次事务，Esc 或指针取消恢复原路径；双击拖拽手柄恢复自动计算，双击线条或文字编辑关系文字；只读及导出显示保存的路径，不显示调整手柄
- 选中关系线后，空心圆标出起点，实心圆标出箭头端；拖动圆形手柄更换对应节点，可连接的节点会高亮；松手后重新计算路径并保存到同一事务，保留关系文字和样式，支持撤销；落在空白处、原节点、自身或已有的同向连接上不修改关系线
- 节点默认无背景、不显示边框，正文格式通过节点内的 Protyle 编辑；选中节点后，脑图面板底部显示单排配色工具栏，仅展示节点配色及颜色管理入口，复用外观面板中的文字色与背景色组合，包含内置及自定义颜色并遵循其顺序和可见性，可恢复默认色；点击树连线或关系线，在脑图面板底部显示对应的设置菜单，线条颜色复用外观背景色，菜单不显示标题栏、虚线及宽度控件；双击关系线文字，在原位置显示输入框进行编辑
- 滚轮或触控板滚动用于移动画布，Ctrl + 滚轮或触控板双指捏合以鼠标位置为中心缩放；工具栏提供缩放、适应画布和全屏；全屏沿用编辑器的窗口内全屏及窗口控件避让，点击全屏按钮或按 Esc 退出并回到原列表位置
- 本次不包含概要和自由摆放节点

## 数据与兼容性

正文仍存放在原列表和原列表项中，搜索、块引用和反链继续使用原块 ID。单个顶层列表项直接作为根节点；多个顶层项使用可自定义标题的虚拟中心节点，它不新增实际块，标题存放在脑图属性的可选 `rootTitle` 字段中。

列表块使用 `custom-sy-list-mindmap="1"` 启用脑图视图。`custom-sy-list-mindmap-data` 保存版本为 `1` 的节点样式和关系线配置。关闭脑图视图保留该配置；折叠使用列表项的已有 `fold` 属性。未知版本或损坏的配置不会被自动覆盖，原列表仍可查看。

关系线可选的 `route` 字段使用独立的 `version: 1`，`points` 保存不超过 64 个控制点。每个控制点的 `x`、`y` 是相对两个节点中心插值位置的偏移，`t` 是沿路径长度计算的插值比例（0 到 1），坐标偏移的绝对值不超过 1000000。缺少 `route` 表示自动路径；双击恢复时只删除该字段，保留文字、样式和端点。旧配置无需迁移，未知路径版本及损坏配置保留原值。节点位置变化时重新避障，暂时无法使用的手动路径仍保留配置并显示自动路径，恢复可用布局后重新使用手动路径。拖动期间的外部刷新取消预览，提交前核对关系线快照，避免覆盖较新的配置。

修改前补齐折叠隐藏的列表内容。结构、正文和配置修改通过已有文档事务保存，并进入文档撤销记录。复制列表时，样式所关联的节点 ID 和关系线的端点随复制后的块 ID 一起更新。

内核在文档事务完成结构修改后，按列表当前的完整节点树清理失效的样式及关系线，并将配置修改附加到同一事务的同步、撤销和重做记录中。普通列表编辑、其他窗口和通过文档事务执行的 API 删除共用此逻辑；同一事务内先删除再插入的节点及折叠后代不会被误清理。刷新脑图只读取配置，不执行清理；复制列表会过滤不属于副本的样式和关系线。未知版本及损坏配置保持原样。

节点内容编辑保留原正文块的身份和属性，以及穿插在正文之间的子列表。编辑器中新建的列表在结束该次编辑时转换为实际子节点。外部更新导致编辑目标失效时，不覆盖较新的正文，并显示尚未保存的内容供恢复。

脑图 DOM、画布、全屏占位和编辑器均为派生显示内容，不写入列表事务或剪贴板的思源块数据。此功能沿用现有块存储、加密、历史和备份格式。

关系线路由使用带进出方向约束的正交网格搜索，按节点边界及目标位置选择连接点，禁止立即折返。路线代价综合长度及转弯，各条关系线独立计算，不避让已有线条；新增连接的吸附预览与落点使用相同规则。节点宽度变化时可选择与目标对齐的连接点，节点和折叠、添加按钮仍作为避让区域。

再次拖动手动路径时移动保存的控制点，自动避障拐点不转成固定约束；往回拖过相邻折线时收起被跨过的控制点，进入端点区域时将控制点退到两节点之间，避免绕行路径无法缩回。

## 导出与验证

思源格式的 HTML 和 PDF 预览沿用 `Protyle.mindmapRender` 加载列表脑图，资源均来自本地。Markdown、Markdown 格式的 HTML 和 Word 保留列表形式。

从 `app/` 运行 `pnpm run lint`。列表模型、真实 DOM 与 Lute、编辑生命周期、导出和菜单配置的回归测试位于 `src/protyle/render/listMindmap/`、`src/protyle/export/listMindmapExport.test.ts` 和 `src/config/entryVisibility/`。真实浏览器测试使用独立 Electron 实例，不启动或重启思源内核；没有图形显示环境的 Linux 会跳过浏览器部分。
