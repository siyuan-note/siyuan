# h265heic

本目录派生自 `github.com/gen2brain/h265/heic` v0.1.1，用于 SiYuan 的受限 HEIF 静态图像预览。代码保留上游 MIT 许可证，并在容器、参数集、NAL、网格、单帧、累计编码数据和解码内存层增加资源边界。

该适配层只接受 `hvc1`、单个 IDR VCL NAL、最高 10-bit 4:2:0 或单色且不含透明辅助图的静态图像，单个容器和累计实际解码数据均不得超过 32 MiB，不支持 HEIF 序列。若扩展到多 slice、CRA、非 IDR、透明辅助图或序列，必须先为底层 HEVC 解码器增加对应的累计工作量和总 DPB 资源上限。

上游的 MIT 许可证不授予 HEVC 编解码相关专利权；发布包含该解码器的二进制前，应单独确认目标分发地区和使用方式所需的专利许可。
