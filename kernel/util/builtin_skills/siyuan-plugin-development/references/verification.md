# 验证记录

每一项只报告实际证据：已通过、失败、未验证或不适用。源码和 ZIP 完成不能替代运行证据。

- 源码：实现对应确认的方案，前端与资源声明准确，没有未批准的数据影响
- 静态检查：确实运行的语法、类型或 lint 检查及结果；没有解析器就写未验证
- 构建：TypeScript 实际命令、退出状态与产物；纯 JavaScript 为不适用
- ZIP：package_local 返回的包路径、hash、源码版本、清单和校验结果
- 模拟测试：标明 SDK 替身、DOM 或独立 Electron 环境，不称为真实思源
- 安装：授权的目标、包 hash、安装前后版本及真实原生安装结果
- 启用：实际配置状态，不能从安装成功推断已经启用
- 前端加载：Electron 桌面和桌面浏览器分别检查入口与错误，不能互相代替
- 业务运行：主操作、错误反馈、重复点击、部分初始化卸载、迟到异步响应
- 数据写入：目标、数量、实际返回状态；未知结果先只读核实，避免重复提交

没有真实思源实例、目标前端或必要权限时，明确保留未验证阶段。不要安装到用户真实环境来弥补缺少测试环境。代码回退不回退用户数据。

恢复不保证自动处理所有进程崩溃：临时文件仅写入部分内容，或条件新建已发布目标但尚未清理临时硬链接时，工具保留两份名称、字节和日志并返回 result_unknown，可能需要人工检查。不要删除不确定的文件、放宽硬链接检查或盲目重试来宣称恢复完成。
